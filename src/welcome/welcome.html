v0.1.0-beta AegisGate Lens

AegisGate Lens is a privacy-first browser extension that detects prompt injection, PII, secrets, and toxicity before they reach AI tools like ChatGPT, Claude, and Gemini.

Privacy promise

No prompt content ever leaves your browser. Not for debugging. Not for support. Not ever.

The Lens is a privacy product. The default is OFF for telemetry. You must explicitly opt in to share anonymized threat-intel signals.

What gets checked

  • Prompt injection — the content of the page or document you paste into the AI, not just what you typed
  • PII — SSNs, emails, phone numbers, credit cards, addresses, etc.
  • Secrets — API keys, OAuth tokens, private keys, database connection strings
  • Toxicity — hate, threats, self-harm

Default: off

The Lens is in detect-only mode by default. It will show you a warning banner before you send a prompt that contains something sensitive — but it will not send any data anywhere.

Opting in to threat intel (optional)

If you opt in, the Lens sends a small, anonymous "I detected X category Y" signal back to AegisGate. This helps the AegisGate Gateway (our enterprise product) become smarter over time. The signal contains:

  • A hashed version of the page domain (e.g. a3f1c8d2b9e07456) — not the URL, not the path, not any page content
  • The category that was detected (e.g. pii_email) — not the value
  • The severity and your action (send, redact, cancel)

See docs/PRIVACY-POLICY.md for the full policy.

You can change this any time from the extension popup (click the AegisGate icon in the toolbar).
